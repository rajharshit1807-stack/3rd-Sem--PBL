# 🏨 Smart Hostel Management System

A C++ project focused on simplifying hostel room management, student records, and leave requests using DSA and OOP.

### Features
- Room allocation and occupancy tracking
- Add, remove, and search students
- Hash Table with Linked List collision handling
- Leave request submission and approval
- CSV-based data storage

### Tech Stack
**C++** · **OOP** · **Hash Table** · **Linked List** · **Circular Queue** · **File Handling**

Built as an academic project to apply Data Structures and OOP concepts to a real-world hostel management problem.
